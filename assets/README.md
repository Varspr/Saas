# assets/

## body_tpose.obj

Сюда кладётся базовый меш тела — нейтральный **SMPL-X в T-pose, размер M**
(Фаза 3 плана). Это статичная модель-носитель: в MVP без кастомизации тела.

Файл **не** хранится в репозитории (большой + лицензия SMPL-X требует
регистрации). Получить: https://smpl-x.is.tue.mpg.de/ → экспорт T-pose в `.obj`.

Если файла здесь нет, `backend/app/pipeline/body.py` автоматически сгенерирует
примитивный манекен из цилиндров/сфер и закэширует его сюда — этого хватает,
чтобы mock-пайплайн отдавал валидный `.glb`.

Путь настраивается через `BODY_MESH_PATH` в `.env`.
